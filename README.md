## Filling out the form Telegram with messages via Bot, writing to .xlsx document, syncing with Google Sheets

1. Clone the project:
```
git clone https://github.com/Kerensk1y/News_parser.git
```
2. Create virtual environment
```
python3 -m venv venv
```
Use the following command to activate venv
```
source venv/bin/activate
```
Use this command to deactivate venv
```
deactivate
```
3. Install the requiered modules:
```
pip3 install -r requierments.txt
```
4. Try to run it
```
nohup python3 -u pkl_bot.py &
```
